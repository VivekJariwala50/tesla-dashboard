# ⚡ Tesla Cybertruck Dashboard

A premium, interactive 3D dashboard for the Tesla Cybertruck, built with **React**, **Three.js**, and **Tailwind CSS**. This project features a fully interactive 3D model, real-time status monitoring, and a sleek, glassmorphic UI.

![Tesla Dashboard Preview](https://images.unsplash.com/photo-1566008885218-90abf9200ddb?auto=format&fit=crop&q=80&w=2000)

## 🚀 Live Demo
[View Live Project](https://tesla-cybertruck-dashboard.vercel.app/) *(Placeholder)*

## ✨ Key Features

-   **🎮 Interactive 3D Visualization**: High-fidelity Cybertruck model with real-time animations.
-   **🔄 Dynamic Wheel Physics**: Wheels rotate realistically based on driving speed and gear selection.
-   **💡 Smart Lighting Control**: Toggle headlights and taillights with emissive material updates.
-   **🔋 Real-time Telemetry**: Monitor battery level, range, speed, and gear status.
-   **📱 Responsive Design**: Fully optimized for mobile, tablet, and desktop displays.
-   **📍 Advanced Navigation UI**: Mock GPS interface with route start and overview capabilities.
-   **❄️ Climate & Security**: Interactive controls for climate systems, door locks, and frunk.

## 🛠️ Tech Stack

-   **Frontend**: React 19, TypeScript
-   **3D Engine**: Three.js, @react-three/fiber, @react-three/drei
-   **Styling**: Tailwind CSS, Lucide React (Icons)
-   **Build Tool**: Vite
-   **Animations**: Framer Motion (planned) / Three.js Hooks

## 📥 Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/VivekJariwala50/tesla-dashboard.git
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Run the development server**:
    ```bash
    npm run dev
    ```
4.  **Build for production**:
    ```bash
    npm run build
    ```
